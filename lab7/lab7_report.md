## 3. Выполненные задачи

### 3.1. Настройка проекта и подключение к GigaChat

- Реализован загрузчик `.env`.
- Настроен класс `GigaChatAssistant` для работы с API.
- Добавлен пример `test_connection.py` для проверки доступности сервиса.

### 3.2. Генерация функций

С помощью модуля `generated_code.py` реализованы функции:
- `validate_email(email: str) -> bool` — проверка email с регулярным выражением и проверкой домена.
- `sort_by_key(data: List[Dict], key: str, reverse: bool = False) -> List[Dict]` — сортировка списка словарей.
- `timer(func)` — декоратор для измерения времени выполнения функции.

### 3.3. Рефакторинг плохого кода

Исходный файл `bad_code.py` не соответствовал требованиям:
- нечёткие имена переменных и функций;
- отсутствовали типы и docstring;
- использовалась глобальная переменная.

В результате получен файл `refactored_code.py` с:
- понятными именами функций и переменных;
- типизацией и документацией;
- константами вместо глобальных переменных;
- обработкой ошибок в функции поиска пользователя.

### 3.4. Генерация тестов

Подготовлен файл `test_refactored.py` с минимум 7 тестами для:
- арифметики;
- обработки списка;
- поиска пользователя;
- валидации email;
- сортировки и декоратора `timer`.

### 3.5. Анализ и документация

- `README_generated.md` содержит инструкцию по установке и использованию модуля.
- `report/analysis.json` и `report/answers.md` описывают качество кода и найденные проблемы.

## 4. Техническая реализация

### 4.1. Файл `gigachat_client.py`

- `generate_code`
- `refactor_code`
- `generate_tests`
- `generate_documentation`
- `analyze_code`

Внутри реализован разбор Markdown и очистка ответа от ` ```python `, чтобы возвращался только чистый код.

Запуск `pytest test_refactored.py -v` проверяет основные сценарии. Ожидаемый результат: все тесты проходят без ошибок.
