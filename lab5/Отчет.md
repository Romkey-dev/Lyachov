## 4. Основные запросы

### 4.1 SQL-запросы

#### Запрос 1. Заказы с суммой
```sql
SELECT 
    o.order_id,
    u.full_name,
    o.order_date,
    o.status,
    SUM(oi.quantity * oi.unit_price) AS total_amount
FROM orders o
JOIN users u ON o.user_id = u.user_id
JOIN order_items oi ON o.order_id = oi.order_id
GROUP BY o.order_id, u.full_name, o.order_date, o.status
ORDER BY total_amount DESC;
```

#### Запрос 2. Выручка по категориям
```sql
SELECT 
    p.category,
    SUM(oi.quantity) AS total_sold,
    SUM(oi.quantity * oi.unit_price) AS total_revenue
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
GROUP BY p.category
HAVING SUM(oi.quantity * oi.unit_price) > 10000
ORDER BY total_revenue DESC;
```

#### Запрос 3. Топ-3 пользователя (CTE)
```sql
WITH user_totals AS (
    SELECT 
        u.user_id,
        u.full_name,
        SUM(oi.quantity * oi.unit_price) AS total_spent
    FROM users u
    JOIN orders o ON u.user_id = o.user_id
    JOIN order_items oi ON o.order_id = oi.order_id
    GROUP BY u.user_id, u.full_name
)
SELECT * FROM user_totals
ORDER BY total_spent DESC
LIMIT 3;
```

### 4.2 MongoDB-запросы

#### Чтение заказов Alice с суммой
```javascript
db.orders.aggregate([
    { $lookup: { from: 'users', localField: 'user_id', foreignField: '_id', as: 'user_info' } },
    { $unwind: '$user_info' },
    { $match: { 'user_info.email': 'alice@example.com' } },
    { $addFields: { total_amount: { $sum: { $map: { input: '$items', as: 'item', in: { $multiply: ['$$item.quantity', '$$item.price'] } } } } } },
    { $project: { _id: 1, user: '$user_info.full_name', status: 1, total_amount: 1, items: 1 } }
]);
```

#### Топ-3 пользователя по сумме заказов
```javascript
db.orders.aggregate([
    { $unwind: '$items' },
    { $group: { _id: '$user_id', total_spent: { $sum: { $multiply: ['$items.quantity', '$items.price'] } } } },
    { $sort: { total_spent: -1 } },
    { $limit: 3 },
    { $lookup: { from: 'users', localField: '_id', foreignField: '_id', as: 'user' } },
    { $unwind: '$user' },
    { $project: { full_name: '$user.full_name', total_spent: 1 } }
]);
```

## 5. Ответы на вопросы

### 5.1 Разница между WHERE и HAVING
- `WHERE` фильтрует строки до группировки.
- `HAVING` фильтрует результаты после применения агрегатных функций.

### 5.2 Почему нужно перечислять все неагрегированные столбцы в GROUP BY
PostgreSQL требует, чтобы все выбранные поля, которые не участвуют в агрегатной функции, были определены однозначно. Это необходимо для корректного группирования и чтобы СУБД знала, как агрегировать данные.

### 5.3 Как изменится результат EXPLAIN ANALYZE после добавления индекса
- До индекса план обычно использует `Seq Scan` — полное последовательное сканирование таблицы.
- После индекса план сменится на `Index Scan` — СУБД быстро находит только нужные строки по индексу.
- В результате обычно уменьшается время выполнения и количество прочитанных строк.

### 5.4 SQL vs NoSQL
- В PostgreSQL связи строятся через `FOREIGN KEY` и `JOIN`.
- В MongoDB связи обычно задаются вложенными документами или `$lookup`.
- Реляционная модель удобнее для строгой целостности, документная — для гибкости и быстрого чтения вложенных данных.
