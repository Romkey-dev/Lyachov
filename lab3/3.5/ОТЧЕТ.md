## Структура проекта
Проект расположен в папке `3.5\pwa-news` и содержит:
- `server/` — Node.js backend на Express
  - `index.js`
  - маршруты для получения новостей, поиска, VAPID ключа и подписки на push
- `public/` — клиентская веб-часть
  - `index.html`
  - `css/styles.css`
  - `js/app.js`
  - `js/pwa.js`
  - `sw.js`
  - `manifest.json`
  - `icons/`

## Реализованные задачи

### 1. Серверная часть
Реализован backend на Express с такими возможностями:
- `GET /api/news` — загрузка новостей по категории через внешний API
- `GET /api/news/search` — поиск новостей по запросу
- `GET /api/vapid-public-key` — передача публичного VAPID ключа
- `POST /api/subscribe` — регистрация подписки push
- `POST /api/send-notification` — отправка уведомлений зарегистрированным подписчикам

Для работы используются `axios`, `cors`, `dotenv`, `web-push`.

### 2. Клиентская часть
Реализовано PWA-приложение с:
- выбором категорий новостей
- поиском новостей
- обработкой ошибок сети
- офлайн-индикатором
- показом кешированных статей через IndexedDB
- установкой приложения на устройство

### 3. Service Worker
Реализован `sw.js` с функциями:
- кэширование статических ресурсов (`index.html`, CSS, JS, manifest)
- стратегия кеш-первично для GET-запросов
- обработка офлайн-запросов к документам
- push-события и клик по уведомлению

### 4. PWA-манифест
Создан `manifest.json` с метаданными:
- `name`, `short_name`, `description`
- `start_url`, `display`, `theme_color`, `background_color`
- иконки для установки
