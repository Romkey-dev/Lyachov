## 1. Цель работы
Получить практические навыки создания кроссплатформенного мобильного приложения на React Native, изучить архитектуру с мостом (Bridge), научиться работать с нативными модулями через Expo и реализовать общую кодовую базу для Android и iOS.

## 2. Структура проекта
Проект реализован в папке `GeoNotes` и использует архитектуру с разделением по папкам:
- `src/types/` — типы данных приложения;
- `src/utils/` — работа с SQLite через Expo SQLite;
- `src/store/` — Redux Toolkit для управления состоянием заметок;
- `src/hooks/` — типизированные хуки для Redux;
- `src/screens/` — экраны списка, создания и просмотра заметок.

## 3. Реализация задания
### 3.1. Файл `src/types/index.ts`
Определены типы `GeoNote` и `AppState` для данных заметок и состояния приложения.

### 3.2. Файл `src/utils/database.ts`
Реализованы CRUD-операции для хранения заметок в локальной базе SQLite:
- `initDatabase()` — инициализация таблицы;
- `getNotes()` — загрузка заметок;
- `addNote()` — добавление новой заметки;
- `updateNote()` — обновление заметки;
- `deleteNote()` — удаление заметки.

### 3.3. Файл `src/store/notesSlice.ts`
Реализованы асинхронные действия через `createAsyncThunk`:
- `loadNotes` — загрузка данных из БД;
- `saveNote` — сохранение новой или обновлённой заметки;
- `removeNote` — удаление заметки.

### 3.4. Файл `src/screens/NotesListScreen.tsx`
Реализован главный экран приложения с выводом списка заметок, индикатором загрузки и кнопкой добавления.

### 3.5. Файл `src/screens/AddNoteScreen.tsx`
Реализован экран создания заметки с:
- запросом разрешений на камеру и геолокацию;
- определением текущей позиции;
- возможностью сделать фото;
- сохранением заметки в БД.

### 3.6. Файл `src/screens/NoteDetailScreen.tsx`
Реализован экран просмотра заметки с картой и кнопкой удаления.

### 3.7. Файл `App.tsx`
Собрана навигация приложения через React Navigation и подключён Redux Store.

## 4. Ответы на вопросы
**1. В чем заключается архитектура React Native и как работает мост (Bridge)?**
React Native использует JavaScript код, который общается с нативными компонентами через "мост". Это позволяет писать бизнес-логику на одном языке и вызывать нативные модули, такие как камера или геолокация.

**2. Как обеспечивается кроссплатформенность кода в React Native?**
Большая часть UI и логики реализуется на JavaScript/TypeScript, а нативные API инкапсулируются в модули Expo и React Native. Это позволяет запускать один и тот же код на Android и iOS.
