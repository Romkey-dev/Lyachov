# Activity Tracker

Кроссплатформенное мобильное приложение для отслеживания физической активности, разработанное на **Flutter**.

## Функциональность

- 📊 **Отслеживание активности** - ходьба, бег, велосипед, тренажерный зал
- 📈 **Статистика** - общая информация и разбор по типам тренировок
- 💾 **Локальное хранилище** - сохранение всех данных в SQLite БД
- 🎨 **Красивый UI** - Material 3 дизайн с поддержкой темной темы
- ⚡ **Плавные анимации** - анимированное прогресс-кольцо с использованием CustomPaint
- 📱 **Кроссплатформенность** - работает на Android и iOS

## Установка

### Требования
- Flutter SDK 3.0+
- Dart 3.0+
- Android SDK (для Android) или Xcode (для iOS)

### Шаги установки

1. **Клонирование репозитория**
```bash
cd activity_tracker
```

2. **Получение зависимостей**
```bash
flutter pub get
```

3. **Запуск на эмуляторе/устройстве**
```bash
flutter run
```

4. **Создание release сборки**
```bash
# Android
flutter build apk --release

# iOS (требуется macOS)
flutter build ios --release
```

## Используемые зависимости

- **provider** (6.1+) - управление состоянием
- **sqflite** (2.3+) - локальная база данных SQLite
- **intl** (0.18+) - интернационализация и форматирование
- **sensors_plus** (4.0+) - доступ к датчикам устройства
- **location** (5.0+) - работа с геолокацией

## Основные компоненты

### Models
- **ActivityRecord** - данные о одной тренировке
- **UserStats** - общая статистика пользователя
- **DailyStats** - статистика за один день

### Services
- **DatabaseService** - CRUD операции с тренировками
- **SensorService** - имитация работы датчиков

### Providers (State Management)
- **ActivityProvider** - управление списком тренировок и текущей тренировкой
- **SensorProvider** - управление данными с датчиков
- **ThemeProvider** - управление темой приложения

### Widgets
- **ActivityCard** - отображение одной тренировки
- **ProgressRing** - анимированное кольцо прогресса (кастомный виджет)

## Особенности реализации

### 1. Использование CustomPaint для анимаций
```dart
class _ProgressRingPainter extends CustomPainter {
  void paint(Canvas canvas, Size size) {
    // Рисование прогресс-кольца напрямую на Canvas
    canvas.drawArc(...); // рисование дуги
  }
}
```

### 2. Реактивное управление состоянием
```dart
Consumer<ActivityProvider>(
  builder: (context, provider, child) {
    // UI автоматически перестраивается при изменении provider
  },
)
```

### 3. Работа с базой данных
```dart
// Сохранение тренировки
await databaseService.insertActivity(activity);

// Получение всех тренировок
List<ActivityRecord> activities = await databaseService.getAllActivities();

// Удаление тренировки
await databaseService.deleteActivity(activityId);
```
