## Часть 1. Нативная Android-разработка с Jetpack Compose

### Цель
Освоить создание Android-приложения на Kotlin с использованием Jetpack Compose, MVVM, Room и Flow.

### Выполненные задачи
- Создан проект `NotesApp` с архитектурой MVVM.
- Реализована модель `Note` с полем `createdAt`.
- Настроен Room: `NoteDao`, `NoteDatabase`, `NoteRepository`.
- Реализован `NotesViewModel` с `StateFlow` и реактивным обновлением UI.
- Создан интерфейс на Jetpack Compose:
  - список заметок;
  - экран создания/редактирования заметки;
  - навигация через `NavHost`.

### Результат
Рабочее приложение для создания, редактирования, удаления и просмотра заметок с сохранением в локальную базу и корректной реактивной перерисовкой UI.

## Часть 2. Кроссплатформенное приложение на React Native

### Цель
Изучить React Native, архитектуру с мостом (Bridge), работу с нативными API и Expo.

### Выполненные задачи
- Реализовано приложение `GeoNotes` для геометок и заметок.
- Использован Redux Toolkit для управления состоянием.
- Настроено хранение в SQLite через Expo SQLite.
- Созданы экраны:
  - список заметок;
  - создание заметки с камерой и геолокацией;
  - просмотр заметки с картой.
- Реализован поиск, CRUD и синхронизация с базой.

### Результат
Кроссплатформенное мобильное приложение, работающее на Android и iOS, с возможностью добавлять геометки, фотографировать, сохранять данные локально и просматривать заметки на карте.

### Выполненные задачи
- Разработано приложение `Activity Tracker`.

## Часть 4. Kotlin Multiplatform Mobile (KMM)

### Цель
Разработать общий модуль логики и данных для KMM и подключить его в Android-приложении на Jetpack Compose.

### Выполненные задачи
- Создан общий KMM-модуль `shared`.
- Настроена SQLDelight-схема и запросы.
- Реализованы модели `Category`, `Expense`, `Budget`, `CategoryStats`.
- Написан общий класс `Database` с CRUD для категорий, расходов и бюджета.
- Реализован Android UI через Compose, использующий общий модуль.

### Результат
Рабочий каркас ExpenseTracker, демонстрирующий возможность единой бизнес-логики для Android и других платформ через KMM.
