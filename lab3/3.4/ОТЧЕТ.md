## Структура проекта
Проект расположен в папке `3.4\ExpenseTracker` и содержит:
- `shared/` — общая KMM библиотека
  - `commonMain/kotlin/` — модели, репозиторий, ViewModel, утилиты
  - `commonMain/sqldelight/` — схема SQLDelight, запросы
  - `androidMain/` — реализация драйвера базы данных для Android
  - `iosMain/` — заглушка под iOS
- `androidApp/` — Android-приложение на Jetpack Compose
  - `MainActivity.kt`
  - `ui/ExpenseTrackerApp.kt`
  - `ui/ExpensesScreen.kt`

## Реализованные задачи

### 1. Общий модуль базы данных
Реализован общий класс `Database` на Kotlin Multiplatform для работы с SQLDelight:
- `addCategory()` — добавление категории расходов
- `addExpense()` — добавление расхода
- `getAllCategories()` — потоковое получение категорий
- `getAllExpenses()` — потоковое получение расходов
- `deleteExpense()` — удаление записи
- `addBudget()` — установка бюджета по категории
- `getCategoryStats()` — вычисление статистики по категориям за месяц

Используются `Flow`, `Dispatchers.Default` и `kotlinx-datetime`.

### 2. SQLDelight
Создана схема `ExpenseDatabase.sq` с таблицами:
- `category`
- `expense`
- `budget`

Реализованы запросы:
- `insertCategory`
- `selectAllCategories`
- `insertExpense`
- `selectAllExpenses`
- `deleteById`
- `sumByCategory`
- `countByCategory`
- `insertBudget`
- `getBudgetByCategory`

---

### 3. Общие модели
Созданы следующие модели в `shared/src/commonMain/kotlin/com/example/expensetracker/models`:
- `Category`
- `Expense`
- `Budget`
- `CategoryStats`

Модели поддерживают работу с ID, суммами, датами и флагом синхронизации.

### 4. Android-клиент на Jetpack Compose
Android-приложение использует общий KMM-модуль:
- `DatabaseDriverFactory` создает SQLDelight драйвер для Android
- `ExpenseTrackerApp` инициализирует `Database` и передает его на экран
- `ExpensesScreen` отображает список расходов и категории
