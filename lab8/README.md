# Fullstack Lab 17 — Deploy & CI/CD

Проект-образец для лабораторной работы по облачному деплою и настройке CI/CD.

Структура:

- `frontend/` — пример фронтенда (Next.js) с инструкцией
- `backend/` — FastAPI приложение, Dockerfile, requirements
- `infrastructure/` — заготовки Terraform и CI/CD
- `.github/workflows/` — примеры workflow для GitHub Actions
- `Отчёт(1).md` — обязательный отчёт (в формате, как вы запросили)

См. также папки `frontend` и `backend` для локального запуска и инструкций.
