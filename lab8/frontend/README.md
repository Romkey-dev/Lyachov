# Frontend (Next.js) — instructions

Это placeholder для фронтенд-приложения на Next.js (портфолио). Для выполнения лабораторной вы можете скопировать ваш проект из ЛР 10.2 сюда.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run start
```

Добавьте `NEXT_PUBLIC_API_URL` в Vercel или `.env.production` при деплое.
